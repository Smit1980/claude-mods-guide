# Mods Guide

Самостоятельная статическая страница о модах Claude Code. Откройте `index.html` в браузере; сборка, сервер и внешние зависимости не нужны.

`yasen.png` добавляется отдельно и используется в hero и блоке проекта ЯСЕНь.

Статус сведений указан в верхнем уведомлении страницы: базовые возможности и минимальные версии зафиксированы на 6 октября 2026; данные о сторонних модах перенесены из исходника с датой 3 октября 2026 и требуют самостоятельной проверки перед использованием.
