01 / ОРИЕНТАЦИЯ

Что такое мод и где он действует

Мод — небольшой пакет JavaScript или TypeScript, который работает внутри Claude Code. Он получает события: отправку запроса, планируемый инструментальный вызов или отрисовку части интерфейса. Мод может пропустить событие, дополнить его либо ответить сам — например, остановить рискованную команду. Поэтому возможны панели, status line, изменённый индикатор работы и slash-команды без обращения к модели.

Мод — разновидность плагина: его устанавливают, обновляют и удаляют теми же средствами.

Где запускается Claude CodeМод выполняетсяИнтерфейс мода
claude в терминалеДаДа
Вкладка Code в Claude DesktopДаДа, кроме элементов, работающих только в терминале
Расширение VS CodeДаНет
Автоматический claude -pДаНет

Полоса над строкой ввода, где живут Token Weather и Next steps, есть только в терминале. Используйте этот гид как маршрут: проверьте версию, создайте тестовый мод, а чужой код ставьте только после проверки.

02 / ПРОВЕРКА

Убедитесь, что среда готова

Терминал 
claude update
claude --version

Если после обновления терминальная версия ниже 2.1.287, возможна задержка стабильного канала. В Claude Code откройте /config → Auto-update channel → latest. В Homebrew исходник различал claude-code (стабильный) и claude-code@latest (новый) пакеты.

Проверка механизма модов 
claude plugin test

Ответ no hooks module to load означает, что механизм модов доступен, но в текущей папке нет мода для загрузки. Формулировка, что моды выключены in this process, означает удалённое отключение установленных модов: локальная настройка это не исправит.

03 / ПЕРВЫЙ МОД

Соберите Token Weather за одну сессию

Контекст — переписка и материалы, которые модель удерживает в пределах своего окна. Token Weather показывает заполнение и рост этого окна. Для эксперимента создайте отдельную папку и откройте в ней Claude Code.

Терминал · macOS / Linux 
mkdir -p ~/Desktop/demo-mods && cd ~/Desktop/demo-mods && claude
Промпт 
Создай мод token-weather для Claude Code: погодный индикатор контекстного окна в полосе над вводом.
В одной строке показывай:
• До 25% — ☀ Ясно, жёлтый; 25–49% — ☁ Облачно, голубой; 50–74% — ☂ Дождь, синий; 75–89% — ☇ Гроза, пурпурный; от 90% — ↯ Пора сжимать, красный.
• Процент заполнения и число использованных токенов относительно размера окна, например 134.4k / 200k.
• График последних 12 ходов символами ▁▂▃▄▅▆▇█.
• Прирост последнего хода, например ▲ +98.3k.
Обновляй строку после каждого хода.
Английский вариант исходной идеи
Prompt 
Create a token-weather mod for Claude Code, in the band above the prompt.
Show a weather state: under 25% clear (yellow), 25–49% cloudy (cyan), 50–74% showers (blue), 75–89% storm (magenta), 90%+ compact soon (red).
Include usage percentage, used/total tokens (134.4k / 200k), a 12-turn ▁▂▃▄▅▆▇█ chart, and the last-turn increase (▲ +98.3k). Refresh after every turn.

При создании Claude Code попросит доступ к служебной папке ~/.claude, поскольку там появляются файлы мода. Разрешение давайте только после понимания, что именно будет создано. Для hot reload выберите Enable for this session, чтобы увидеть изменения без перезапуска.

Уточнение 
Пусть гроза начинается с 70%.
Уточнение 
Добавь в конце строки стоимость в долларах.

Когда индикатор появился, попросите Claude прочитать несколько больших файлов и наблюдайте изменение погоды. Правки обычным текстом применяются с горячей перезагрузкой. Суть подхода: опишите желаемый результат, а реализацию поручите встроенному навыку plugin-authoring. Его можно открыть вручную командой /plugin-authoring.

04 / СОХРАНЕНИЕ

Перенесите удачный мод из временной сессии

Сделанный в сессии мод хранится в ~/.claude/dev-mods/<номер-сессии>/<имя-мода>/. Это временное место, которое Claude Code может очистить. Перенесите рабочий вариант в собственный каталог и оформите его как marketplace.

Промпт 
Скопируй мод token-weather из папки dev-mods этой сессии в ~/my-mods/token-weather. Создай в ~/my-mods файл .claude-plugin/marketplace.json с этим модом и покажи две команды, чтобы установить его для всех моих сессий.
Шаблон marketplace.json
JSON 
{
  "name": "my-mods",
  "owner": { "name": "Local" },
  "plugins": [{ "name": "token-weather", "source": "./token-weather" }]
}
Подключить marketplace 
claude plugin marketplace add ~/my-mods
claude plugin install token-weather@my-mods --scope user
Запустить папку мода на одну сессию 
claude --plugin-dir ~/my-mods/token-weather

В уже открытом Claude Code после установки введите /reload-plugins.

05–07 / ОФИЦИАЛЬНЫЕ ПРИМЕРЫ И КАТАЛОГ

Три примера и каталог Anthropic

Blast Radius

Задерживает опасную команду: удаление каталога, откат Git, force push или миграцию базы. Объясняет последствия и предлагает выполнить или отменить; отмена выбрана по умолчанию.

Token Weather

Визуализирует заполнение контекста.

Replay Theater

Команда /replay воспроизводит по шагам изменения последнего ответа.

Next steps

В исходнике он предлагает до трёх дальнейших запросов после ответа: 1–3 подставляют вариант во ввод, 0 скрывает предложения. Состояние каталога проверяйте перед установкой.

Клонировать примеры и открыть один мод 
git clone https://github.com/anthropics/claude-code-playground.git
cd claude-code-playground/claude-code/mods
claude --plugin-dir ./blast-radius

Blast Radius — дополнительная страховка. Он анализирует текст команды: опасное действие внутри скрипта или за псевдонимом может остаться незамеченным. Для строгого запрета нужны правила разрешений Claude Code.

Вместо ./blast-radius можно использовать ./token-weather или ./replay-theater. Для постоянной установки из той же папки сначала добавьте каталог как marketplace, затем установите выбранный пакет через интерфейс /plugin или CLI.

Постоянная установка примера из каталога claude-code-playground/claude-code/mods:

Установить Blast Radius 
claude plugin marketplace add ./
claude plugin install blast-radius@claude-code-playground-mods --scope user

Каталог модов: claude.dev/mods. По состоянию исходника на 3 октября там были примеры, встроенные моды и Next steps.

Добавить community marketplace и Next steps 
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install next-steps@claude-community

Перезагрузите моды командой /reload-plugins, если сессия уже открыта.

09 / СВОИ ИДЕИ

Найдите повторяющуюся работу

Лучшие моды обычно появляются там, где вы снова и снова даёте одно указание, вручную проверяете один статус или теряете контекст при длинной задаче.

Промпт для аудита работы 
Прочитай мои последние сессии Claude Code. Найди задачи, которые я делаю часто, указания, которые повторяю, и места, где я теряю время. Предложи пять модов под мою работу, пронумеруй их и объясни, что делает каждый.
Английский вариант
Prompt 
Look through my session logs and identify the tasks I do often, the instructions I repeat, and the friction in my workflow. Suggest five useful Claude Code mods based on those patterns, and explain what each would do.
Сначала десять идей 
Придумай десять идей модов для Claude Code под мою работу. Для каждой напиши, что она показывает или меняет и зачем мне. Пронумеруй.
Затем выбрать и реализовать 
Сделай идеи 1, 2 и 7. Проверь их в Claude Code и объясни, как ими пользоваться.

Перед показом результатов аудита сессий проверьте их сами: в истории могут быть личные данные. Не выводите такую историю в запись экрана без проверки.

10 / БЕЗОПАСНОСТЬ

Проверяйте мод как исполняемый код

Мод способен работать с теми же ресурсами, которые доступны вам: читать файлы и .env, запускать программы, обращаться в сеть, вызывать MCP-инструменты, отправлять prompts и расходовать доступ к модели. Не устанавливайте незнакомый пакет в рабочую среду «на доверии».

У модов нет собственной песочницы. Даже если Bash-команды Claude изолированы, процесс, запущенный модом, работает за пределами этой песочницы. Мод может одобрять действия до пользовательского запроса разрешения.

В исходнике отмечен встроенный защитный мод cc-plugin-sec-default при наличии управляемых администратором настроек либо входе по тарифу Team или Enterprise: он не разрешает действия, запрещённые политикой deny. На личной подписке, с API-ключом или облачными провайдерами без управляемых настроек этот сторож не загружается: мод может одобрить даже действие, запрещённое личным deny-правилом. Даже со сторожем запрет чтения .env инструментами Claude не запрещает самому моду вызвать $.fs.read. Если визуальный мод запрашивает сеть, секреты и запуск процессов, его возможности не соответствуют заявленной задаче — не устанавливайте его.

Проверка скачанной папки 
claude plugin validate ./папка-мода

В результате смотрите hooks: (на что реагирует) и calls: (какие действия заявлены). События tool.call и prompt.submit означают, что мод видит действия или запросы и потенциально способен на них влиять.

ВызовРиск / действие
$.fs.read, $.fs.writeЧтение и запись файлов с вашими правами.
$.process.run, $.process.spawnЗапуск программ от вашего имени.
$.http.fetchСетевые обращения и возможная передача данных.
$.env.get, $.settings.readЧтение окружения и настроек, где могут быть секреты.
$.env.setИзменение окружения Claude Code и его процессов.
$.mcp.callВызов подключённых MCP-серверов.
$.model.completeРасход доступа к модели, подписки или API-ключа.
$.prompt.submit, $.session.sendОтправка запросов и сообщений от вашего имени.
Отключение и удаление
  • Один мод: /plugin → Installed → выключить, или claude plugin disable <мод>@<маркетплейс>.
  • Все моды только в запуске: claude --safe-mode. Это затронет и другие настройки.
  • Все hooks: в ~/.claude/settings.json установите "disableAllHooks": true. Это остановит и обычные hooks, включая скрипты событий и status line.
  • Удалить мод: claude plugin uninstall <мод>@<маркетплейс>.
  • Удалить marketplace: claude plugin marketplace remove <название>.
  • Посмотреть активные моды: /plugin; под вкладками есть строка состояния, например 1 mod active · token-weather.
